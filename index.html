Os dados ficam salvos no navegador. Ao fechar a aba, o sistema pergunta se deseja fazer backup.
Dica: Mova o arquivo HTML para dentro da pasta do OneDrive — assim o backup baixado ficará junto e sincronizado automaticamente.
Como integrar com OneDrive:
1. Abra o OneDrive e crie uma pasta chamada RepCRM
2. Mova este arquivo HTML para dentro dessa pasta
3. Os backups baixados irão para a pasta Downloads — mova-os para a pasta RepCRM do OneDrive
4. Ou altere a pasta padrão de downloads do Chrome para a pasta OneDrive/RepCRM
Clique para restaurar backup (.json)
Para IA real com Claude, adicione sua API Key. Sem ela, a IA usa análise local dos dados.
